Превью модов для секции «Небольшие моды» на projects.html.

Клади сюда картинки 16:9 (например 640x360) и указывай путь
в массиве MODS внутри projects.html:

  { kind:"qol", name:"Мой мод", note:"Что делает.",
    url:"https://modrinth.com/mod/...", img:"images/mods/moimod.jpg" },

Если файла нет — карточка сама покажет пиксельную заглушку,
страница не сломается.
